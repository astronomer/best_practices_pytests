Overview
========

This is an attempt to create pytests to enforce dag writing best practices through pytest. 

Project Contents
================

Standard Astro project, with examples of bad dag-writing behavior, and pytests in /tests that will catch those behaviors. Each example dag explains why the behavior is considered bad practice, and each test provides corrective feedback with links to Astronomer or Airflow docs.
